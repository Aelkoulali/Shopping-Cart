# 🗂️ Shopping Cart 🛒

A simple Shopping Cart built with HTML, CSS, and JavaScript. It lets users manage cart items and see updated totals instantly.

## ✅ Features
- Add items to the cart
- Update quantities / remove items
- Real-time cart total calculation

## 🧠 JavaScript Concepts Used
- Methods for data manipulation
- Ternary operator (conditional rendering/logic)
- Spread operator (copy/update arrays/objects)
- `this` keyword (within functions/classes)

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript

## ▶️ How to Run
Open `index.html` in your browser.
